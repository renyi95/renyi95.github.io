高德地图 Web JS API 2.0 接入与使用指南

发表于 2026-08-24 分类于 javascript 阅读次数：

本文整理高德地图 Web JS API 2.0 在原生 JavaScript 和 Vue 3 项目中的接入方式，并给出点标记、信息窗体、定位、地址解析、路线规划等常见功能示例。

本文示例面向中国大陆版 Web JS API 2.0。Key、配额、计费与合规要求可能调整，上线前请以高德开放平台控制台和官方文档为准。

一、接入前准备

1.1 创建应用和 Key

  1. 登录高德开放平台控制台。
  2. 进入「应用管理」并创建应用。
  3. 在应用中添加 Key，服务平台选择「Web 端（JS API）」。
  4. 保存生成的 Key 和 安全密钥 securityJsCode。
  5. 在控制台配置可使用该 Key 的域名白名单，并为开发、测试、生产环境分别创建 Key。

2021 年 12 月 2 日之后申请的 Web 端 Key 必须配合安全密钥使用。注意不要误选「Web 服务」Key，Web 服务 Key 主要供服务端 REST API 使用。

十一、坐标系说明

高德地图使用 GCJ-02（火星坐标系）。常见数据源可能使用其他坐标系：

数据来源常见坐标系
GPS、国际通用经纬度WGS84
高德、腾讯、国内 GoogleGCJ-02
百度地图BD-09

如果标记整体偏移数百米，优先检查坐标系。不要只通过手动增减经纬度“校准”，应使用合规的坐标转换接口。经纬度数组的顺序是 [longitude, latitude]，即 [经度, 纬度]。

十二、常见问题排查

12.1 地图空白

依次检查：

  1. 容器是否有非零高度，创建地图时容器是否已挂载。
  2. 浏览器控制台和 Network 中是否有鉴权或资源加载错误。
  3. Key 是否为「Web 端（JS API）」类型，是否配置了正确域名。
  4. window._AMapSecurityConfig 是否在 Loader 或 JS API 之前设置。
  5. 页面 CSP、广告拦截器或公司代理是否拦截了高德资源。
  6. 弹窗或 Tab 从隐藏切换为显示后，是否调用了 map.resize()。

12.2 INVALID_USER_KEY 或鉴权失败

  • Key 填写错误或已被删除、禁用；
  • Key 类型不匹配；
  • 域名白名单不包含当前域名；
  • Key 与安全密钥不属于同一个应用；
  • 安全配置执行得太晚；
  • 调用量或服务权限超出控制台限制。

12.5 定位失败

确认页面为 HTTPS、浏览器有位置权限，然后记录 status、result.message 和完整错误对象。定位属于外部能力，产品上应允许用户手动选点或输入地址。

十三、上线检查清单

  • 使用 Web JS API 2.0，未混入旧版本脚本。
  • 开发、测试、生产 Key 已隔离。
  • Key 配置了最小范围的域名白名单。
  • 生产环境通过 serviceHost 代理保护安全密钥。
  • 地图容器有稳定尺寸，隐藏容器显示后会触发 resize()。
  • Vue/React 组件卸载时销毁地图实例和监听器。
  • 用户输入的信息窗体内容已经防 XSS 处理。
  • 定位具备授权提示、失败提示和手动选址降级方案。
  • 已确认业务坐标系，检查经纬度顺序。
  • 已核对最新配额、计费、服务权限和合规要求。
